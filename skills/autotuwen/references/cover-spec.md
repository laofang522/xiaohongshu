# 封面与附图规格

## 封面（便签贴纸风，用户审定样式）
- 底图：真实教室/备课照片，3:4（1080×1440），优先有老师授课瞬间的教室照
- 便签：圆角矩形 (255,244,180,242)，旋转 -5°，居中偏下
- 文字：手写体（macOS Hanzipen.ttc）
  - 第 1-2 行：深灰(50,50,50) 小字，地域+家长处境（「在宁波，小学英语六年怎么走」）
  - 第 3 行：红色(200,50,40) 大字关键词（「就四件事」）+ 绿色(120,190,120) 彩笔下划线 10px
- 封面文字必须让目标家长一眼识别科目（含「英语」或教材名）和处境
- 备选风格：粉色圆角小标签（双轨闭环式）、白底标签条——用户点名要才用

## 附图
- 默认裸图不加任何文字（标注贴不准反而减分，已被用户否决两次）
- 真实素材：练习卷/词汇测试/阅读材料/白板板书/课本页
- 学生正脸需遮挡（贴纸或裁掉）
- 不用网图、AI 图、过度设计素材
